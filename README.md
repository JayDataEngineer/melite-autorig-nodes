# melite-autorig-nodes

rig transfer + weight surgery (KimodoExportFBX, soma_weight_transfer, blender_retarget, validate_rig, weight_surgery).

Tech Noir Auto-Rig bridge nodes for ComfyUI.

## Nodes

- `ARMATURE`
- `Authorization`
- `Hips`
- `KimodoExportFBX`
- `KimodoTransferWeights`
- `LoadGLBAsTrimesh`
- `MESH`
- `RayCleanWeights`
- `RaySyncSiblingWeights`
- `SaveRiggedModel`
- `SomaNPZToOpenPose`
- `VEC4`

## Install

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/JayDataEngineer/melite-autorig-nodes.git
```

Restart ComfyUI.
